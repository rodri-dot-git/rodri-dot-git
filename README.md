### About Me

Hey there! I'm Rodrigo, a software engineer. I build production web applications end to
end — mostly TypeScript on Next.js and React, with Postgres underneath and a Python layer
wherever the data work gets heavy. Most of what I ship runs in regulated environments for
clients, so my day-to-day is less about greenfield demos and more about systems that have
to stay correct under real load: high-volume ingestion and analytics pipelines on AWS,
internal operations tooling, and the auth, audit, and access-control plumbing that makes
both usable by people who aren't engineers.

I care about doing things the right way from the start. In practice that means schema-first
database design and migrations that never trade away data; real test suites — Vitest,
Testing Library, Playwright — rather than tests written to hit a coverage number; and
infrastructure wired properly, with federated credentials instead of long-lived keys,
secrets in a secrets manager, and errors reported somewhere a human will actually see
them. I came up through QA, and it still shows in how I scope work: I'd rather find the
edge case in review than in production.

Day to day that's Next.js, React, Tailwind and shadcn on the front end; Prisma or Drizzle
over Postgres; Auth.js, passkeys and argon2 for anything touching identity; and Vercel,
Railway or AWS depending on what the workload needs. Outside the web stack I write Python
— FastAPI, pandas, scikit-learn, graph analytics — for data-heavy backends, Swift and
SwiftUI for native iOS, and I've spent enough time in C# and .NET to still be useful
there. I speak Spanish and English.
